# Historical design records

Files in this directory are retained, non-normative evidence. They preserve
original rationale and superseded design statements so later maintainers can
understand why the current contract differs.

The [original specification](Specification.md) is classified rule by rule in
the [issue #68 disposition record](../../audits/2026-07-27-issue-68-specification-disposition.md).
The sole maintained specification is the
[normative v0.2 contract](../v0.2-contract.md).

Moving a document here does not make any statement in it current. A historical
record must carry the repository's historical marker and an unmistakable
status banner. Current normative authority requires the distinct claimant
marker enforced by the repository documentation check.
