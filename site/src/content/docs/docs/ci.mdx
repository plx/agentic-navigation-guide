With the CLI installed, run this from the repository root to require a valid
guide:

```sh
agentic-navigation-guide verify --deny-ignored
```

For repositories with multiple guides:

```sh
agentic-navigation-guide verify --recursive --deny-ignored
```

Each discovered guide is verified relative to its parent directory. The run
fails if any guide fails, is ignored, or no guides are found. Leave out
`--deny-ignored` only if your check intentionally permits ignored guides;
use `--allow-empty` only for optional searches.

## GitHub Actions

Add this step after checkout and CLI installation:

```yaml
- name: Verify navigation guides
  run: agentic-navigation-guide verify --recursive --github-actions-check --deny-ignored
```

`--github-actions-check` selects file-and-line diagnostics and exits `1` on a
verification failure. It does not reject ignored guides on its own.

The repository maintains a
[complete workflow example](https://github.com/plx/agentic-navigation-guide/blob/main/.github/examples/readme-verify.yml)
with pinned actions and an exact CLI version. Its crates.io installation step
requires v0.2.0 to be published. Until then, use the
[source-checkout installation](../#install).

## Local hooks

A pre-commit hook can run:

```sh
agentic-navigation-guide verify --pre-commit-hook --deny-ignored
```

For a post-tool-use hook:

```sh
agentic-navigation-guide verify --post-tool-use-hook --deny-ignored
```

Post-tool-use mode exits `2` on verification failure. The
[README hook example](https://github.com/plx/agentic-navigation-guide#claude-code-post-tool-use-hook)
shows how to attach it to Claude Code tools that may change files.
