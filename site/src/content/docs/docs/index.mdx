`agentic-navigation-guide` checks the paths in hand-maintained repository maps
for coding agents. You choose which files to mention and write the comments;
the CLI checks guide syntax, path names, and file and directory types.

It does not check whether comments describe the code correctly, require a
complete listing, or update a guide when files move.

## Install

These docs describe the prepared **v0.2.0 CLI**. `0.2.0` is prepared but not
published. From the root of a trusted source checkout, with Rust 1.85 or later
installed:

```sh
cargo install --path . --locked
```

After v0.2.0 is published on crates.io:

```sh
cargo install agentic-navigation-guide --version 0.2.0 --locked
```

v0.2 provides an executable, with no Rust library API. For upgrades, uninstalling,
and migration from v0.1.4, see the
[repository README](https://github.com/plx/agentic-navigation-guide#install-upgrade-and-uninstall).

## Create a guide

Run this from the project directory you want to describe:

```sh
agentic-navigation-guide init --output AGENTIC_NAVIGATION_GUIDE.md
```

`init` creates a starting guide from the directory tree. It requires an explicit
output path and refuses to overwrite an existing file.

Edit the result to keep the paths and comments that help someone find their way
around. For example, a guide for this repository could contain just:

```md
<agentic-navigation-guide>
- src/
  - parser.rs # Guide syntax
  - verifier.rs # Filesystem checks
- Cargo.toml
</agentic-navigation-guide>
```

Other files may exist. You do not need to list them or add a placeholder.

## Check it

From the same project directory:

```sh
agentic-navigation-guide verify
```

If the guide is valid and its listed paths match the filesystem, the output is:

```text
✓ Navigation guide is valid and matches filesystem
```

A missing path or a file listed as a directory makes verification fail. Run it
after editing a guide, or add it to [CI](./ci/).

See [Commands](./commands/) for other invocations and
[Guide format](./guide-format/) for syntax. The
[full reference](https://github.com/plx/agentic-navigation-guide/blob/main/docs/v0.2-contract.md)
covers all options, platform support, and filesystem limitations.
